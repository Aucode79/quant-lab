# cycle-etf-rotation — 周期 ETF 轮动研究（因子检验 + 周期结构 + 三门策略）

围绕"行业周期时钟"假设的完整量化研究：先检验假设（因子有效性、周期结构是否存在），再构建策略（三门状态机轮动），最后做稳健性与安慰剂检验。研究口径：周期组（煤炭/有色/钢铁/化工/建材/机械）、防御组（医药/医疗/消费/公用事业）、创业板基准。

## 研究流程

### 1. 因子诊断（`factor_diagnosis.py` → `factor_diagnosis.csv`）

逐 ETF 计算：年化波动、效率比 ER20/ER60、**方差比 VR5/VR20/VR60**（随机游走检验）、多阶自相关（AC1/20/60/250）、MA250 穿越频率、最大回撤与深回撤持续天数。

### 2. 因子有效性检验（`factor_ic_test.py`）

- **因子库**：多窗口对数动量（mom20/60/120/250）、长期位置 z-score（pos250/pos500）、波动状态比（volratio = v20/v252）；
- **Spearman 秩 IC**：各因子 × 20/60/120/250 日前瞻窗口的 pooled IC，判别周期板块"动量 vs 反转"哪个方向成立；
- **共同驱动检验**：pairwise-complete 相关矩阵 PCA，PC1 方差占比与特征值条件数；分期间（2018-20 / 21-22 / 23-26）相关性稳定性；CYC→DEF 篮子领先滞后结构。

### 3. 结果快照（面板 2058 交易日 × 11 ETF，2018-01 ~ 2026-06，见 `ic_results.txt`）

- **"周期时钟"存在**：周期组两两平均相关 **+0.578**、PCA PC1 方差占比 **65.5%**（防御组仅 +0.248 / 44.1%），且跨三个子期间稳定（+0.70 / +0.54 / +0.58）——共同驱动假设有实证支持；
- **中期动量有效**：周期组 mom120 / pos250 在 120 日前瞻窗口 pooled IC ≈ **+0.29**（250 日窗口 +0.19~0.26）；短窗口动量为负（mom60 fwd60 = −0.10，短期呈反转倾向）；volratio 全窗口为负（高波动状态 = 负向风险标记）；
- **诚实负结果**：周期组对防御组**无显著领先滞后**（k=±1~5 日相关全部归零，仅同期 +0.35）——"煤炭领先钢铁"式的时钟结构在本样本中不成立。

### 4. 周期结构估计（`industry_clock_spectral.py`）

- **行业领先滞后（T1）**：个股收益对市场 beta 中性化取残差 → 周频行业篮子 → 非对称度 A(i→j)=corr(i_t, j_{t+2})−corr(j_t, i_{t+2})；**分半稳定性** + **循环移位置换检验（500 次）**构造零分布并报告 p 值（附多重比较下的随机期望）；
- **周期长度谱估计（T2）**：等权周期篮子去 beta、减 250 日移动平均趋势后，对月度序列做 **FFT 周期图**，聚焦 1.5–8 年频段取前 5 功率峰；**逐年 jackknife**（每次剔除一年重估主峰）检验谱峰稳定性；诚实报告频率分辨率极限；
- **相关 regime（T3）**：滚动 60 日板块间平均两两相关 vs 未来 60 日篮子收益，非重叠采样 + IC + 三分位分组。

### 5. 策略回测（`cycle_etf_v0.py`）

三门状态机（risk_on / neutral / risk_off）ETF 轮动：信号 t 日生成、t+1 日 14:50 执行（无未来函数自检通过），含交易成本。

### 6. 稳健性与安慰剂

参数网格扰动（N×EXIT）、执行价口径切换（exec_close / signal_lag2）、滑点倍增压力测试（slip_2x / slip_3x）；安慰剂对照组（cyc_ew / def_strategy / noncycle / benchmark）。

## ⚠️ 已知问题（重要）

主回测与安慰剂模块的输出**明显失真**（Sharpe>100、滑点增大反而改善、安慰剂组成交笔数=0 且指标全为 0）。初步判定 bug 位于回测引擎的执行/统计环节，与上述诊断、IC、谱估计脚本（独立计算）无关，正在排查。原始输出保留作为研究记录，**请勿引用其绝对数值**。

8 年样本本身就是结构性限制——所有结论在解读时都要打折扣（脚本内已注明）。
