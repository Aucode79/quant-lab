# momentum-rolling — 动量滚仓（周度 ETF 动量轮动）

本策略的完整演进史（聚宽 5 个版本迭代 → 实盘 → 迁移本地）见 **[`evolution.md`](evolution.md)**：含各版本代码（`jq_versions/`）、聚宽回测截图（`backtests/`）与逐版优化逻辑复盘。

## 策略逻辑（`backtest_v1.py`，本地版）

- **标的池**：4 只跨资产 ETF（游戏/纳指/红利低波/黄金——经 V1.2.2 按**相关性正交**原则收敛后的池子，详见 evolution.md），分散单一市场风险。
- **信号**：每周一计算 20 日动量得分 = 区间收益 / 年化波动（收益除以波动）；过滤条件为收益 > 0 且现价 > MA20；无合格标的则持现金避险。
- **执行**：每周一次调仓，信号分最高者满仓；滑点 0.1% + 佣金（含最低 5 元）成本建模；本金 10 万。
- **验证**：同一策略在聚宽（JoinQuant）平台独立实现并对比（脚本尾部记录对标结果：收益 88% / 回撤 17% / 夏普 1.43，21 盈 11 亏），本地结果与平台口径对齐。
